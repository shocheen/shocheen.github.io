# Selected research figures

These are the original authors' figures from the seven selected papers.
Paper IDs, figure numbers, accessible descriptions, and source links are stored
in `_data/selected_research.json`. The homepage links to the source of each figure.

The tokenization pipeline (PDF page 2, Figure 1.1) and accent-bias overview
(PDF page 1, Figure 1) were rendered directly from their PDF figure regions at
200 DPI. The other figures are original assets from the arXiv HTML versions.
No figures were redrawn and no result values were changed.
HalluWorld's original PNG was encoded as lossless WebP; decoded RGBA pixels were
verified against the original before replacing the local PNG copy.
